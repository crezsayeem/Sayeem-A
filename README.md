# Sayeem A. — Functional Portfolio

## Run locally
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Run `index.html` with the Live Server extension, or open it directly in a browser.

## Personalize before publishing
- Replace `assets/sayeem.jpg` with your portrait (keep the same filename).
- In `script.js`, replace `YOUR_EMAIL@example.com` with your real contact email.
- In `index.html`, replace the sample project links, descriptions, award text and social links with your real information.
- Add your resume PDF at `resume/Sayeem_Akber_Resume.pdf`.
- Review the education and experience dates/details for accuracy.

## Responsive optimization
- Optimized layouts for small phones, large phones, tablets, laptops, desktops and wide monitors.
- Prevents horizontal overflow and reduces text clipping with fluid sizing.
- Larger touch targets and touch-friendly hover behavior.
- Mobile menu closes with Escape and resets cleanly after resizing.
- Landscape phone layout and reduced-motion accessibility support.

## Included functionality
- Responsive desktop, tablet and mobile layout.
- Mobile navigation menu with accessible expanded state.
- Smooth in-page navigation and scroll progress indicator.
- Back-to-top button.
- Scroll reveal animations (respects reduced-motion settings).
- Journey filter buttons: All / Current / Past.
- Contact form validation and `mailto:` message preparation.

## Contact form limitation
This static HTML/CSS/JS website does not store or deliver messages to a server. The contact form validates fields and opens the visitor's configured email application. For server-side delivery without relying on the visitor's email app, connect a form backend or build an API endpoint.

## Important
All portfolio metrics, project descriptions and award cards are editable starter content. Replace anything that is not factually accurate before publishing.


## Cinematic motion & device optimization
- GSAP + ScrollTrigger reveal animations and staggered section entrances.
- Lenis smooth scrolling (desktop wheel; native-feeling touch scrolling on mobile).
- Cinematic hero title reveal, animated portrait/orbits and soft ambient glow.
- Custom glowing cursor and neon click ripple on mouse/trackpad devices only.
- Project card 3D tilt and pointer-following light on capable desktop devices.
- Responsive layouts for phones, tablets, laptops, desktops and wide displays.
- Reduced-motion preference is respected automatically.

GSAP, ScrollTrigger, Lenis and Google Fonts load from their CDNs, so an internet connection is needed for those enhancements. The page content remains readable if those services are unavailable.
